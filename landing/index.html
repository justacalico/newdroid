F-Droid, without the wait.

NewDroid is a fast F-Droid client for Android. Browse the catalog, install and update apps with verified downloads, and plug in any F-Droid-compatible repository.

Free software under the AGPL v3.

Built to stay out of the way.

A client for the F-Droid ecosystem that loads fast, refreshes cheap and never phones home.

Incremental index refresh

ETag-aware index fetching means refreshes transfer only what changed. The catalog stays warm on disk, so browsing starts instantly — even offline.

Verified installs

Every APK is checked against the index SHA-256 before Android sees it. Signature-aware update detection flags mismatches instead of failing silently.

Bring your own repos

F-Droid, IzzyOnDroid and Guardian Project presets ship in the box, and any index-v2 or index-v1 repository can be added by URL.

Free software, end to end

AGPL v3, no ads, no analytics, no accounts. Releases are built by CI and mirrored to permanent GitLab release downloads.

Install in a minute.

Grab the signed APK from a release and open it — Android handles the rest.

  1. Download newdroid-<version>-android.apk from the releases page.
  2. Open the file on your device and allow installs from your browser when asked.
  3. Launch NewDroid — the F-Droid index loads on first run.
